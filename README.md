# 釣り札作成（Turihuda）

パレットに積む商品に貼る仕分け札（釣り札）を作るためのページです。
サーバー不要で、`index.html` をブラウザで開くだけで使えます。データはブラウザの localStorage に保存されます。

## 使い方

1. `index.html` を開く（Chrome / Edge 推奨）。
2. 「＋ 新しい仕事」で **得意先名** と **受注番号** を入力して作成。受注番号は重複できません。
3. 商品の行に **商品名・商品名補足・セット数** を入力（自動保存）。「＋ 行を追加」で行を増やせます。
4. 「印刷」でプレビューが開き、A4 横で 1 商品（1 パレット）につき 1 枚印刷されます。

一覧画面では仕事ファイルを **開く / 複製 / 削除** できます。複製時も新しい受注番号の入力が必要です。

## 計算ルール（`js/calc.js`）

- 2000 セット = 1 コマ。端数セットは「× 1 コマ」として 1 行追加。
- 8 コマ = 1 段。1 パレット最大 8 段。
- 8 段を超える場合はパレットを分割する。1 段・2 段だけのパレットは作らない。
  - 2 パレット: 9→6+3, 10→6+4, 11→6+5, 12→6+6, 13→7+6, 14→7+7, 15→8+7, 16→8+8
  - 3 パレット: 17→6+6+5, 18→7+6+5, 19→7+7+5, 20→8+7+5, 21→8+8+5, 22→8+8+6, 23→8+8+7, 24→8+8+8
- 分割時は商品名に `-1`, `-2` … を付け、端数コマは最後のパレットに載せる。
